# Самостійна робота №10 — варіант 4

**Дисципліна:** Комп'ютерні та мікропроцесорні системи, організація комп'ютерних мереж  
**Тема:** Стандарти мереж: IEEE 802 і структура RFC  
**Варіант:** 4 — SMTP

## 1. Основний документ RFC

| Поле | Значення |
| --- | --- |
| Номер | RFC 5321 |
| Повна назва | *Simple Mail Transfer Protocol* |
| Рік публікації | 2008 |
| Статус документа | IETF Datatracker показує `Draft Standard` (жовтень 2008); документ належить до Standards Track і замінив RFC 2821 |
| Автор | John C. Klensin |

Джерело: [RFC 5321 у IETF Datatracker](https://datatracker.ietf.org/doc/rfc5321/).

## 2. Чинність документа

RFC 5321 позначає RFC 2821 як застарілий документ (*Obsoletes*). Сам RFC 5321 не замінений новішим базовим RFC SMTP; [RFC 7504](https://datatracker.ietf.org/doc/rfc7504/) уточнює окремі SMTP-відповіді та позначений як документ, що оновлює RFC 5321 (*Updates*). У знімку IETF Datatracker статус RFC 5321 наведено як `Draft Standard` (жовтень 2008).

## 3. Два конкретні факти зі специфікації

1. SMTP використовує TCP-порт **25** для передавання пошти між серверами (RFC 5321, § 4.1.1.2).
2. SMTP-сервер має бути готовий приймати рядки команд довжиною щонайменше **512 октетів**, включно з завершенням CRLF (RFC 5321, § 4.5.3.1.4).

## 4. Підгрупи IEEE 802

| Підгрупа | Область відповідальності |
| --- | --- |
| IEEE 802.1 | Мости, VLAN, керування та архітектура локальних мереж. |
| IEEE 802.3 | Ethernet, зокрема фізичний рівень і керування доступом до середовища. |
| IEEE 802.11 | Безпровідні локальні мережі Wi‑Fi. |

## Контрольні запитання

1. **Чим статус Proposed Standard відрізняється від Internet Standard?** Proposed Standard позначає специфікацію на стандартизаційному шляху IETF, тоді як Internet Standard — зрілий стандарт, офіційно затверджений як інтернет-стандарт. RFC 5321 має статус `Draft Standard` у IETF Datatracker; це конкретний рівень документа на шляху Standards Track.
2. **Що означають поля Obsoletes і Updated by?** Obsoletes означає, що поточний документ замінює названий попередній RFC. Updated by перелічує новіші документи, які змінюють або уточнюють частини цього RFC, не обов'язково замінюючи його повністю.
3. **За що відповідає IEEE 802.1 і чим вона відрізняється від 802.3?** 802.1 охоплює архітектуру, мости та VLAN, а 802.3 визначає Ethernet.
4. **Чому недостатньо знайти будь-який RFC із назвою протоколу?** Старий RFC може бути замінений або частково оновлений. Потрібно перевірити поля Obsoletes та Updated by, щоб посилатися на актуальну базову специфікацію й доповнення до неї.

## Висновок

Для SMTP основною базовою специфікацією є RFC 5321. Перевірка пов'язаних RFC допомагає відрізнити попередню специфікацію від документа, який її замінює, та від подальших уточнень. Родина IEEE 802 охоплює різні частини локальних мереж, зокрема мости/VLAN, Ethernet і Wi‑Fi.
