# Практична робота №6 — варіант 4

## Тема

Мікроконтролерний вузол: GPIO, АЦП, таймер і UART.

## Мета

Закріпити навички роботи з цифровими та аналоговими периферійними інтерфейсами Arduino Uno: перемикання світлодіода кнопкою, зчитування аналогового сигналу, періодичне неблокувальне вимірювання через `millis()` та передавання структурованих даних через UART.

## Завдання варіанта

Варіант 4 — імітація рівня рідини. Показання аналогового датчика потрібно перетворити на відсотки від 0 до 100 і виводити в Serial Monitor у форматі фіксованої ширини, наприклад `LVL |  74|`.

Проєкт Arduino Uno у Wokwi: [відкрити симуляцію](https://wokwi.com/projects/477958840262263809).

## Схема підключення

| Компонент | Підключення |
| --- | --- |
| Кнопка | D2 та GND; вхід налаштований як `INPUT_PULLUP` |
| Світлодіод | D8 через послідовний резистор 220 Ом до GND |
| Потенціометр | Середній вивід — A0, крайні виводи — 5V і GND |

## Код програми

Скетч запускається на Arduino Uno у симуляторі Wokwi. Кнопка перемикає стан світлодіода, а показання потенціометра зчитується раз на секунду. Код не використовує блокувальний `delay()`.

```cpp
const int buttonPin = 2;
const int ledPin = 8;
const int sensorPin = A0;

bool ledState = false;
bool lastButtonState = HIGH;

unsigned long lastMeasurement = 0;
const unsigned long interval = 1000;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // Зчитування стану кнопки та перемикання світлодіода
  bool buttonState = digitalRead(buttonPin);
  if (buttonState == LOW && lastButtonState == HIGH) {
    ledState = !ledState;
    digitalWrite(ledPin, ledState);
  }
  lastButtonState = buttonState;

  // Періодичне неблокувальне зчитування раз на 1000 мс (millis)
  unsigned long now = millis();
  if (now - lastMeasurement >= interval) {
    lastMeasurement = now;

    // Симуляція рівня рідини від 0% до 100%
    int value = map(analogRead(sensorPin), 0, 1023, 0, 100);

    // Вивід у форматі варіанта 4 (поля фіксованої ширини: "LVL |  74|")
    Serial.print("LVL |");
    if (value < 10) {
      Serial.print("   "); // 3 пробіли для однозначного числа
    } else if (value < 100) {
      Serial.print("  ");  // 2 пробіли для двозначного числа
    } else {
      Serial.print(" ");   // 1 пробіл для числа 100
    }
    Serial.print(value);
    Serial.println("|");
  }
}
```

## Пояснення роботи

1. `pinMode(buttonPin, INPUT_PULLUP)` вмикає внутрішній підтягувальний резистор. У ненатиснутому стані на вході D2 зчитується `HIGH`, а при натисканні кнопки, з'єднаної з GND, — `LOW`.
2. Умова `buttonState == LOW && lastButtonState == HIGH` виявляє перехід до натиснутого стану. Після цього `ledState` інвертується, а `digitalWrite()` оновлює вихід D8.
3. `analogRead(sensorPin)` зчитує значення АЦП Arduino Uno в діапазоні 0–1023. Функція `map()` масштабує його до умовного рівня від 0 до 100%.
4. Перевірка `now - lastMeasurement >= interval` запускає вимірювання через інтервал 1000 мс. Віднімання безпечно працює і при переповненні лічильника `millis()`.
5. Перед числом у Serial виводяться пробіли, щоб поле показання мало однакову ширину для одно-, дво- та тризначних значень. Швидкість UART — 9600 бод.

## Результат запуску

У симуляції показання змінюється при обертанні потенціометра, а кнопка перемикає світлодіод. Serial Monitor відображає рядки, наприклад:

```text
LVL |   0|
LVL |  41|
LVL |  65|
LVL |  94|
```

Пробіли перед числом є частиною формату фіксованої ширини.

## Відповіді на контрольні запитання

1. **Для чого призначений `INPUT_PULLUP`?**  
   Він вмикає внутрішній підтягувальний резистор і задає HIGH на вході, коли кнопка розімкнена. Для кнопки між входом і GND зовнішній підтягувальний резистор тоді не потрібен; натискання зчитується як LOW.

2. **Яку розрядність має АЦП Arduino Uno і який діапазон повертає `analogRead()`?**  
   АЦП має розрядність 10 біт, тому `analogRead()` повертає значення від 0 до 1023.

3. **Чому `delay()` у головному циклі є проблемним?**  
   Під час `delay()` виконання циклу блокується. Якщо поставити `delay(1000)`, програма не опитуватиме кнопку приблизно секунду, тож реакція на натискання може затриматися. Періодична перевірка через `millis()` дає змогу виконувати вимірювання за розкладом і продовжувати опитувати кнопку між ними.

4. **Чому важливо заздалегідь продумати формат UART-повідомлення?**  
   Структурований і стабільний формат дає змогу іншій програмі однозначно розділяти та розбирати поля. Роздільники й узгоджена ширина полів зменшують неоднозначність, зокрема якщо дані згодом передаватимуться мережею.

5. **Чим відрізняються синхронний та асинхронний послідовні інтерфейси?**  
   Синхронний інтерфейс передає тактовий сигнал окремою лінією. Асинхронний, як UART, не має окремої лінії тактування: передавач і приймач заздалегідь узгоджують швидкість передачі.

## Висновок

У роботі реалізовано цифровий ввід кнопки з `INPUT_PULLUP`, перемикання світлодіода, зчитування аналогового сигналу потенціометра та його перетворення на рівень від 0 до 100%. Періодичне вимірювання організовано без блокувального `delay()` за допомогою `millis()`, а результат виводиться через UART у форматі фіксованої ширини. Роботу схеми перевірено в симуляторі Wokwi.
