# Домашнє завдання до лекції 12

**Тема:** Продуктивність і паралелізм

## 1. Закон Амдала

Послідовна частка програми `f = 0,25`, паралельна частка `1 - f = 0,75`. Формула:

```text
S = 1 / (f + (1 - f) / p)
```

| Кількість процесорів `p` | Розрахунок | Прискорення `S` |
| ---: | --- | ---: |
| 4 | `1 / (0,25 + 0,75 / 4)` | `2,29` |
| 8 | `1 / (0,25 + 0,75 / 8)` | `2,91` |
| 16 | `1 / (0,25 + 0,75 / 16)` | `3,37` |

Зі збільшенням кількості процесорів прискорення зростає, але приріст стає дедалі меншим, бо чверть програми все одно виконується послідовно. Теоретична межа за нескінченно великої кількості процесорів:

```text
S_max = 1 / f = 1 / 0,25 = 4
```

Тому додавати ядра понад певну кількість стає менш вигідно: послідовна частина обмежує загальне прискорення.

## 2. Тип конфлікту конвеєра

```asm
ADD R1, R2, R3 ; R1 = R2 + R3
SUB R4, R1, R5 ; R4 = R1 - R5
```

Виникає **конфлікт за даними** (data hazard), зокрема залежність читання після запису (RAW). Команда `ADD` обчислює нове значення `R1`, а наступна команда `SUB` читає `R1` до того, як результат `ADD` буде записано до регістрового файла. Без пересилання даних процесору доведеться затримати `SUB`; за наявності forwarding результат можна передати безпосередньо до наступної стадії виконання.

## 3. Приклад конфлікту за керуванням

```c
if (temperature > limit) {
    alarm = 1;
} else {
    alarm = 0;
}
```

Це розгалуження створює конфлікт за керуванням: поки процесор не обчислив умову `temperature > limit`, він не знає, яку з двох гілок виконувати. Конвеєр може почати вибирати команди однієї гілки наперед; якщо прогноз неправильний, ці команди доведеться скасувати й завантажити правильну гілку.

## Відповіді на контрольні запитання

1. **Що таке конвеєрне виконання і яке теоретичне прискорення воно дає?** Виконання команди поділяють на стадії, які одночасно обробляють різні команди. За ідеальних умов конвеєр із `N` стадій наближає пропускну здатність до однієї завершеної команди за такт і для довгої послідовності може дати прискорення, близьке до `N` разів.
2. **Приклади структурного конфлікту, конфлікту за даними і за керуванням.** Структурний: дві команди одночасно потребують єдиного порту пам'яті. За даними: `SUB` читає регістр, який попередня `ADD` ще не записала. За керуванням: процесор не визначив результат умови переходу, але вже вибирає наступні команди.
3. **Чим суперскалярне виконання відрізняється від простого конвеєра?** Простий конвеєр перекриває стадії кількох команд, зазвичай починаючи одну команду за такт. Суперскалярний процесор може вибирати й виконувати кілька незалежних команд за один такт на паралельних виконавчих пристроях.
4. **Що станеться при помилковому передбаченні переходу?** Процесор скасує спекулятивно виконані команди з неправильного шляху, очистить відповідну частину конвеєра й почне виконувати правильну гілку. Це втрачає такти.
5. **У чому суть закону Амдала?** Послідовна частина програми обмежує прискорення, якого можна досягти паралельним виконанням. Зі збільшенням числа ядер приріст зменшується, а граничне прискорення дорівнює `1/f`, де `f` — частка коду, що лишається послідовною.
6. **Що таке big.LITTLE і навіщо потрібні гетерогенні ядра?** Це поєднання продуктивних ядер для важких задач та енергоефективних ядер для легких або фонових задач. Така система балансує швидкодію й енергоспоживання.
7. **Як forwarding усуває конфлікт за даними і коли stall усе одно потрібен?** Forwarding передає вже обчислений результат безпосередньо з однієї стадії конвеєра до наступної команди, не чекаючи запису в регістр. Stall може бути потрібний, якщо результат ще не готовий, наприклад одразу після завантаження з пам'яті (load-use hazard), або якщо потрібного шляху пересилання немає.
8. **Чому теоретичне 4-кратне прискорення SIMD рідко досягається повністю?** Не всі обчислення можна векторизувати; на результат впливають підготовка даних, завантаження з пам'яті, вирівнювання, залежності між операціями та обробка елементів, що не заповнюють вектор повністю.
9. **Яке максимальне прискорення можливе, якщо послідовна частка `f = 0,2`?** За законом Амдала граничне прискорення дорівнює `1/f = 1/0,2 = 5`. До цієї межі можна лише наближатися зі збільшенням кількості ядер.
